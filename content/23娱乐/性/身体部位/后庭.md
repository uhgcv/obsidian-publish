
# 清洗
- 大容量PET瓶+按压泵+软管+替换头，温水。
- 不用直接式、花洒水管转接头。不方便操作。瓶式的可以坐着操作。
- 清洁时间地点：卫生间。最好是大便之后。洗澡之前也可以。
# 润滑
- 形制：尖头挤压瓶，小容量
- 水基润滑液：成分都差不多，看价格。1688显著便宜。此外白色、粘稠度、香味加分。对于后庭设计的成分没必要单独买。
- 硅油：很方便。不用硅胶玩具首选
- 油基：尚未探索。

# 后庭液
- 形制：针管注射。有效成分多为提取物。
- 功效：舒缓、放松、增强快感

# 容纳玩具
- 形制：有底座；硅胶材质

## 肛塞
- 材质：硅胶、金属、玻璃。。。
- 塞型：标准型、阴茎型、弯头型、串珠型
- 塞柄：圆盘型、锚型
- 内容物：实心、电机振动、金属滚珠
- 直径：一般最大40mm,中等34mm
- 长度：一般90-100mm,中等80mm
- 塞柄连接物：无、尾巴（可拆卸或固定）

- 姬欲硅胶电动：黑色，硅胶标准型，34mm粗，89mm总长，55mm内头长，圆盘型硅胶柄，电机振动小程序控制。
- 润裕金属滚珠：金属标准型，40mm粗，100mm总长，锚型黑色硅胶柄，钢滚珠，总重146g
