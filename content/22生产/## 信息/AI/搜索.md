#Firecrawl 

##本地部署
-推荐docker，部署在NAS上，NAS作为服务器，电脑局域网或tailscale组网连接
-修改配置在.env，可随时修改，重启后生效
-本地部署的API_URL就是http://192.168.1.200:3002/，API_KEY默认为空、可以配置
-使用redis/redisinsight作为GUI
--将现有RedisInsight容器加入Firecrawl网络
```
docker network connect firecrawl_backend 392ca815e8ee
```
##Local MCP Server配置
```
{ "mcpServers": { "firecrawl-local": { "command": "npx", "args": [ "-y", "firecrawl-mcp" ], "env": { "FIRECRAWL_API_URL": "http://192.168.1.200:3002" } } } }
```

##搜索优化
-方案LLM>MCP>(FIRECRAWL+SEARXNG+OLLAMA)
-必要性：
--搜索能力高度集成的在线AI会强于本地配置的MCP搜索，这一点在未来会强化
--此方案的优势是，可完全本地部署，三者都有独立功能，单独使用可以被其他节点调用，例如n8n、dify，故也有必要。此方案有MCP调用操作更精细化的优点，缺点是配置更复杂。开源LLM可预见的不会内嵌联网功能。
