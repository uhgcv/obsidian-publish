### 1. 工具与环境类（你在哪里写代码）

| 专有名词       | 中文直译/俗称 | 通俗大白话解释                                             | 关联举例                     |
| :--------- | :------ | :-------------------------------------------------- | :----------------------- |
| **IDE**    | 集成开发环境  | **“一站式厨房”**：写代码、查错、运行全在一个软件里搞定，不用来回切换软件。            | Cursor、PyCharm、VS Code   |
| **插件**     | 插件/扩展   | **“厨房小家电”**：不能单独用，得装进已有的 IDE 里，给它增加新功能（比如加个 AI 助手）。 | GitHub Copilot、Cline     |
| **CLI**    | 命令行界面   | **“黑框框盲操”**：没有花哨的画面，全靠在黑屏幕里打字来控制电脑和 AI 改代码。         | Aider、Claude Code        |
| **云端 IDE** | 网页版开发环境 | **“共享厨房”**：不用在自己电脑上装软件，打开网页就能写代码，自带运行环境。            | Replit                   |
| **终端**     | 命令行窗口   | 就是上面说的那个“黑框框”，用来给电脑下达直接指令的地方。                       | Mac 的 Terminal，Win 的 cmd |
### 2. AI 核心概念类（AI 是怎么工作的）
| 专有名词 | 中文直译/俗称 | 通俗大白话解释 | 关联举例 |
| :--- | :--- | :--- | :--- |
| **LLM** | 大语言模型 | **“AI 的大脑”**：读遍了人类互联网文本的超强大脑，会思考、会写文章、会写代码。 | GPT-4、Claude 3.5、DeepSeek |
| **Prompt** | 提示词 | **“给 AI 的需求说明书”**：你打字告诉 AI “帮我写个贪吃蛇”，这句话就是 Prompt。 | “用 Python 写一个网页计算器” |
| **Token** | 词元 | **“AI 算钱的最小单位”**：可以理解成“字数”。AI 是按处理了多少 Token 来收钱的，一个汉字大概是 1-2 个 Token。 | 包月套餐通常限制每月用多少 Token |
| **上下文** | 上下文/短期记忆 | **“AI 的前情提要”**：你发给 AI 的代码、之前的对话，都算上下文。给的上下文越多，AI 答得越准，但也越烧钱。 | 选中一段代码按 Cmd+L 发给 AI |
| **RAG** | 检索增强生成 | **“给 AI 开卷考试”**：怕 AI 瞎编（幻觉），先让它去查你的项目代码或最新文档，再根据查到的真实内容回答。 | AI 工具里的 `@Codebase` 或 `@Docs` 功能 |
### 3. AI 编程动作类（AI 怎么帮你写）
| 专有名词 | 中文直译/俗称 | 通俗大白话解释 | 关联举例 |
| :--- | :--- | :--- | :--- |
| **Autocomplete / Tab** | 自动补全 | **“输入法联想升级版”**：你写一半，它灰字提示下半句，按 Tab 键直接采纳。 | Cursor 的 Tab 预测 |
| **Inline Edit** | 行内编辑 | **“原地施法”**：在代码中间唤出输入框，让 AI 直接把你选中的旧代码改写成新代码。 | Cursor 的 `Cmd+K` |
| **Chat** | 聊天 | **“跟 AI 请教”**：在侧边栏跟 AI 对话，问它怎么写、哪里错了，它给你答案你自己复制粘贴。 | Cursor 的 `Cmd+L` |
| **Composer / Agent** | 作曲家/智能体 | **“全自动包工头”**：AI 能同时看懂并修改好几个文件，自己建文件、自己写代码、自己改 Bug。 | Cursor 的 `Cmd+I`，Cline |
| **Hallucination** | 幻觉 | **“一本正经地胡说八道”**：AI 脑补出不存在的函数或写错代码，但看起来极其自信。 | 代码跑不通，一查发现 AI 虚构了一个库 |
### 4. 接口与计费类（怎么买和怎么用）
| 专有名词 | 中文直译/俗称 | 通俗大白话解释 | 关联举例 |
| :--- | :--- | :--- | :--- |
| **API** | 应用程序接口 | **“餐厅的传菜窗口”**：让两个软件能沟通的通道。你的 AI 编程工具通过 API 把指令传给大模型，大模型再把代码传回来。 | 调用 OpenAI 的 API |
| **API Key** | 密钥 | **“进门VIP通行证”**：一串以 `sk-` 开头的密码，证明你是付费用户，拿着它才能用别人的 API。 | `sk-xxxxxxxxxxxx` |
| **BYOK** | 自带密钥 | **“自带酒水”**：不用买这个软件自带的 AI 套餐，自己偷偷去别处买个便宜的 API Key 插进来用。 | 在 Cline 里填 DeepSeek 的 API Key |
| **Endpoint / Base URL** | 端点/基础网址 | **“传菜窗口的具体地址”**：告诉工具去哪个网址找 AI 大脑。通常以 `/v1` 结尾。 | `https://api.deepseek.com/v1` |
### 5. 传统开发必知（AI 经常提到）
| 专有名词 | 中文直译/俗称 | 通俗大白话解释 | 关联举例 |
| :--- | :--- | :--- | :--- |
| **Bug** | 缺陷/漏洞 | **“代码里的老鼠屎”**：导致程序报错、闪退或算错数的错误。 | 网页点不动了，肯定有 Bug |
| **Debug** | 调试 | **“抓虫子”**：一行行排查代码，找出 Bug 在哪并修好。 | 把报错信息发给 AI 让它 Debug |
| **Git** | 版本控制系统 | **“超级后悔药”**：给代码随时拍快照存档，改崩了能一秒退回上一个能用的版本。 | `git commit`, `git push` |
| **Repository (Repo)** | 仓库 | **“代码的大本营”**：一个项目里所有文件、代码、历史记录存放的文件夹。 | 在 GitHub 上下载别人的 Repo |
| **Framework** | 框架 | **“半成品精装房”**：别人已经搭好的基础结构，你只需要往里面填自己的家具（业务逻辑），不用从打地基开始写。 | Vue, React, Django |
