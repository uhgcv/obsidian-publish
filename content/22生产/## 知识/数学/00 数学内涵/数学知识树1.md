## 数学知识体系全景图

### 一、数学基础 Foundation
> 整个现代数学的公理化根基

| 子领域 | 内涵 | 外延 |
|--------|------|------|
| **数理逻辑** | 形式推理系统、证明论、模型论、递归论、可计算性 | 计算机科学、人工智能、语言学、分析哲学 |
| **集合论** | 集合运算、映射、基数/序数、选择公理、ZFC系统 | 全部现代数学的语言基础、测度论、拓扑学 |
| **范畴论** | 对象与态射、函子、自然变换、泛性质、极限/余极限 | 代数拓扑、代数几何、类型论、函数式编程 |

### 二、代数学 Algebra
> 研究运算结构与对称性

| 子领域 | 内涵 | 外延 |
|--------|------|------|
| **线性代数** | 向量空间、线性映射、矩阵、特征系统、内积空间、张量 | 量子力学、机器学习、计算机图形学、数据分析、经济学 |
| **抽象代数** | 群（对称）、环（算术）、域（方程）、模、伽罗瓦理论 | 密码学、编码理论、晶体学、粒子物理标准模型 |
| **表示论** | 群/代数的线性表示、特征标、Peter-Weyl定理 | 量子物理、调和分析、组合数学、数论 |
| **数论** | 素数分布、同余、Diophantine方程、L函数、模形式 | 现代密码学（RSA/椭圆曲线）、编码理论、代数几何 |
| **泛代数/同调代数** | 一般代数结构、链复形、导出函子、Ext/Tor | 代数拓扑、代数几何、范畴论 |

### 三、几何与拓扑 Geometry & Topology
> 研究形状、空间与连续性

| 子领域 | 内涵 | 外延 |
|--------|------|------|
| **欧氏/非欧几何** | 公理化体系、双曲/椭圆几何、变换群 | 广义相对论、宇宙学、艺术、导航 |
| **微分几何** | 光滑流形、张量分析、黎曼度量、曲率、联络 | 广义相对论、规范场论、机器人学、计算机视觉 |
| **代数几何** | 多项式方程的解集、概形、层论、相交理论、 motive | 数论（Fermat大定理）、弦理论、密码学、优化 |
| **拓扑学** | 同伦群、同调/上同调、纤维丛、示性类、TDA | 量子场论、拓扑数据分析、经济学均衡理论、材料科学 |
| **辛几何** | 辛流形、Lagrange子流形、矩映射 | 经典力学、镜像对称、动力系统 |

### 四、分析学 Analysis
> 研究极限、无穷与变化

| 子领域 | 内涵 | 外延 |
|--------|------|------|
| **实分析** | 测度论、Lebesgue积分、L^p空间、收敛性、函数逼近 | 概率论、偏微分方程、信号处理、经济学 |
| **复分析** | 解析函数、Cauchy积分、留数、共形映射、Riemann面 | 流体力学、量子力学、控制论、数论、信号处理 |
| **泛函分析** | 无穷维空间、线性算子、谱理论、Banach/Hilbert空间 | 量子力学、偏微分方程、优化、控制论、机器学习 |
| **调和分析** | Fourier变换、小波、群表示、极大函数、乘子理论 | 信号/图像处理、PDE、数论（加法组合）、量子物理 |
| **变分法** | 泛函极值、Euler-Lagrange方程、极小曲面 | 物理（最小作用量）、材料学、图像分割、经济学 |

### 建议学习路径

**基础路线（理论导向）：**
集合论/逻辑 → 线性代数 → 数学分析 → 抽象代数（群环域） → 点集拓扑 → 微分流形/黎曼几何

**应用路线（建模导向）：**
微积分 → 概率统计 → 数值方法/科学计算 → 优化理论 → 微分方程 → 专业方向（金融/生物/工程等）

**现代统一视角：**
范畴论 → 同调代数 → 代数拓扑/代数几何 → 表示论 → 数学物理/数论前沿
