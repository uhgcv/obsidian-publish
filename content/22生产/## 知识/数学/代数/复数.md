

虚数和复数是数学中重要的概念，它们扩展了实数系统，解决了负数开平方的问题。以下是系统性的介绍：

---

## 一、虚数（Imaginary Numbers）

### 定义
虚数单位 **i**（在工程领域常用 **j**）定义为：
$$i = \sqrt{-1}$$

这意味着：
$$i^2 = -1$$

### 虚数的形式
纯虚数可以表示为：
$$bi$$
其中 $b$ 是实数，$i$ 是虚数单位。

**例子：**
- $3i$（因为 $(3i)^2 = 9i^2 = -9$）
- $-5i$
- $\sqrt{-4} = 2i$

---

## 二、复数（Complex Numbers）

### 定义
复数是实数和虚数的组合，形式为：
$$z = a + bi$$

其中：
- $a$ 称为**实部**（Real Part），记作 $\text{Re}(z)$
- $b$ 称为**虚部**（Imaginary Part），记作 $\text{Im}(z)$
- $i$ 是虚数单位

### 复数的分类
| 类型 | 条件 | 例子 |
|------|------|------|
| 实数 | $b = 0$ | $5, -3, \sqrt{2}$ |
| 纯虚数 | $a = 0, b \neq 0$ | $3i, -2i$ |
| 一般复数 | $a \neq 0, b \neq 0$ | $3 + 4i, 1 - 2i$ |

---

## 三、基本运算

### 1. 加减法
$$(a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i$$

**例子：**
$$(3 + 2i) + (1 - 4i) = 4 - 2i$$

### 2. 乘法
$$(a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i$$

**例子：**
$$(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i$$

### 3. 除法
通过乘以**共轭复数**来有理化分母。

复数 $z = a + bi$ 的共轭复数为 $\bar{z} = a - bi$

$$\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{(ac + bd) + (bc - ad)i}{c^2 + d^2}$$

**例子：**
$$\frac{1 + i}{1 - i} = \frac{(1 + i)^2}{(1 - i)(1 + i)} = \frac{1 + 2i + i^2}{1 - i^2} = \frac{2i}{2} = i$$

---

## 四、重要概念

### 1. 模（绝对值）
$$|z| = |a + bi| = \sqrt{a^2 + b^2}$$

**例子：** $|3 + 4i| = \sqrt{9 + 16} = 5$

### 2. 共轭复数
$$\overline{a + bi} = a - bi$$

**性质：**
- $z \cdot \bar{z} = |z|^2 = a^2 + b^2$
- $\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2$
- $\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2$

### 3. 辐角（Argument）
复数在复平面上的角度：
$$\theta = \arg(z) = \arctan\left(\frac{b}{a}\right)$$

---

## 五、几何表示：复平面

复数 $z = a + bi$ 可以表示为平面上的点 $(a, b)$：

```
        Im (虚轴)
          ↑
          |     · z = a+bi
          |    /
          |   / r = |z|
          |  /θ
          | /
    ——————+——————→ Re (实轴)
          |
          |
```

- **横轴**：实轴
- **纵轴**：虚轴
- **模 $r$**：点到原点的距离
- **辐角 $\theta$**：与正实轴的夹角

---

## 六、极坐标与指数形式

### 极坐标形式
$$z = r(\cos\theta + i\sin\theta)$$

其中 $r = |z|$，$\theta = \arg(z)$

### 欧拉公式
$$e^{i\theta} = \cos\theta + i\sin\theta$$

因此复数可写为：
$$z = re^{i\theta}$$

**著名的欧拉恒等式：**
$$e^{i\pi} + 1 = 0$$

## 八、简单例题

**例题 1：** 计算 $i^{2026}$

**解：** $i$ 的幂次循环周期为 4：
- $i^1 = i$
- $i^2 = -1$
- $i^3 = -i$
- $i^4 = 1$

$2026 \div 4 = 506$ 余 $2$，所以 $i^{2026} = i^2 = -1$

**例题 2：** 解方程 $x^2 + 4 = 0$

**解：** $x^2 = -4$，所以 $x = \pm\sqrt{-4} = \pm 2i$
