
以下是一份图论学习中**最常用、最容易混淆**的符号速查表，按主题分类整理：

---

## 一、图的基本对象

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $G$ | 图（Graph） | 通常指无向图 |
| $V(G)$ 或 $V$ | 顶点集（Vertex set） | 也写作 $\nu(G)=|V|$ 表示顶点数 |
| $E(G)$ 或 $E$ | 边集（Edge set） | 也写作 $\varepsilon(G)=|E|$ 表示边数 |
| $v_i, u, v, w$ | 顶点 | 小写字母 |
| $e, e_i, uv$ | 边 | $uv$ 表示连接 $u$ 和 $v$ 的边 |
| $\overline{G}$ | $G$ 的补图 | 与原图同顶点集，边集互补 |
| $G[S]$ | 由顶点子集 $S$ 诱导的子图 | $S\subseteq V(G)$ |
| $G-v$ | 删除顶点 $v$ 及其关联边 | 类似 $G-e$ 表示删除边 $e$ |

---

## 二、度数相关

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $d(v)$ 或 $\deg(v)$ | 顶点 $v$ 的度数 | 无向图中与 $v$ 关联的边数 |
| $d^+(v)$ | 出度（out-degree） | 有向图中从 $v$ 出发的弧数 |
| $d^-(v)$ | 入度（in-degree） | 有向图中进入 $v$ 的弧数 |
| $\delta(G)$ | 最小度（minimum degree） | $\min\{d(v):v\in V\}$ |
| $\Delta(G)$ | 最大度（maximum degree） | $\max\{d(v):v\in V\}$ |
| $N(v)$ | $v$ 的邻域（neighborhood） | 与 $v$ 相邻的所有顶点集合 |
| $N^+(v), N^-(v)$ | 出邻域 / 入邻域 | 有向图专用 |

---

## 三、路径、圈与距离

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $P_n$ | 长度为 $n-1$ 的路（Path） | $n$ 个顶点，$n-1$ 条边 |
| $C_n$ | 长度为 $n$ 的圈（Cycle） | $n$ 个顶点，$n$ 条边，$n\geq 3$ |
| $d(u,v)$ | 顶点 $u$ 到 $v$ 的距离 | 最短路径的长度，不连通时为 $\infty$ |
| $\text{diam}(G)$ | 图的直径 | 所有顶点对距离的最大值 |
| $\text{rad}(G)$ | 图的半径 | 所有顶点离心率的最小值 |

---

## 四、连通性

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $\kappa(G)$ | 点连通度（vertex connectivity） | 使图不连通或平凡所需删除的最少顶点数 |
| $\lambda(G)$ | 边连通度（edge connectivity） | 使图不连通所需删除的最少边数 |
| $k$-连通 | $\kappa(G)\geq k$ | 删除少于 $k$ 个顶点仍连通 |
| $\omega(G)$ | 连通分支数 | 不连通图的分支个数 |
| $G$ 是连通图 | $\omega(G)=1$ | |

---

## 五、特殊图类

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $K_n$ | 完全图（Complete graph） | $n$ 个顶点，每对顶点间都有边 |
| $K_{m,n}$ | 完全二分图 | 两部各有 $m,n$ 个顶点，部间全连 |
| $K_{1,n}$ | 星图（Star） | 特殊二分图，一部只有 1 个顶点 |
| $W_n$ | 轮图（Wheel） | $C_{n-1}$ 加一个中心点与所有圈点相连 |
| $Q_n$ | $n$ 维超立方体 | $2^n$ 个顶点，对应 $n$ 位二进制串 |
| $T$ | 树（Tree） | 连通无圈图，边数 = 顶点数 $-1$ |
| $G$ 是森林 | 无圈图 | 若干棵树的并，$\varepsilon = \nu - \omega$ |

---

## 六、图运算

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $G\cup H$ | 并图 | 顶点集与边集的并 |
| $G\cap H$ | 交图 | 顶点集与边集的交 |
| $G+H$ | 联图（Join） | $G\cup H$ 再加 $G$ 与 $H$ 间所有边 |
| $G\times H$ | 笛卡尔积 | 顶点为有序对，按规则连边 |
| $G-v$ | 删点 | 删去 $v$ 及其所有关联边 |
| $G-e$ | 删边 | 仅删去边 $e$ |
| $G/e$ | 收缩边 $e$ | 把边 $e$ 的两个端点捏成一个 |

---

## 七、矩阵表示

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $A(G)$ | 邻接矩阵（Adjacency matrix） | $a_{ij}=1$ 若 $v_i v_j\in E$，否则 0 |
| $D(G)$ | 度对角矩阵 | 对角线上为各顶点度数 |
| $L(G)$ | 拉普拉斯矩阵 | $L = D - A$ |
| $Q(G)$ | 无符号拉普拉斯矩阵 | $Q = D + A$ |
| $B(G)$ | 关联矩阵（Incidence matrix） | 顶点-边关联关系，有向图需定方向 |
| $M(G)$ | 圈矩阵 / 割集矩阵 | 高阶内容 |

---

## 八、染色与匹配

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $\chi(G)$ | 色数（chromatic number） | 正常顶点染色所需最少颜色数 |
| $\chi'(G)$ | 边色数 | 正常边染色所需最少颜色数 |
| $\alpha(G)$ | 独立数 | 最大独立集的顶点数 |
| $\beta(G)$ | 点覆盖数 | 最小点覆盖集的顶点数 |
| $\alpha'(G)$ | 匹配数 | 最大匹配的边数 |
| $\beta'(G)$ | 边覆盖数 | 最小边覆盖集的边数 |
| $\nu(G)$ | 有时也表示匹配数 | 注意与顶点数符号区分上下文 |
| $\tau(G)$ | 顶点覆盖数 | 部分教材用此符号 |

---

## 九、有向图专用

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $D$ | 有向图（Digraph） | Directed graph |
| $A(D)$ 或 $A$ | 弧集（Arc set） | 有向边，有序对 $(u,v)$ |
| $u\to v$ | 从 $u$ 指向 $v$ 的弧 | |
| $\deg^+(v)$ | 出度 | |
| $\deg^-(v)$ | 入度 | |
| 强连通 | 任意两顶点互相可达 | |

---

## 十、王树禾教材特有/常见写法

| 符号 | 含义 | 备注 |
|:---:|:---|:---|
| $\nu$ | 顶点数 $|V|$ | 希腊字母 nu，教材中常见 |
| $\varepsilon$ | 边数 $|E|$ | 希腊字母 epsilon |
| $V_e, V_o$ | 偶次顶点集 / 奇次顶点集 | $e$=even, $o$=odd |
| $G^{(n)}$ | 带参数 $n$ 的图族 | 如例 1.5 中的构造 |
