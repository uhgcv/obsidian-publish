## 一、数学（Mathematics）

数学是希腊字母最密集的领域，几乎每个字母都有约定俗成的语义。

| 字母 | 常见含义 | 使用场景 |
|:---|:---|:---|
| **α, β, γ** | 角度、系数、参数 | 三角函数中的角常用 α, β；γ 用于欧拉常数（≈0.5772） |
| **δ** | 变分、微小量、狄拉克函数 | δx 表示微小增量；δ(x) 为狄拉克 delta 函数 |
| **Δ** | 差分、判别式、拉普拉斯算子 | Δx = x₂−x₁；二次方程判别式 Δ = b²−4ac |
| **ε** | 任意小正数、介电常数 | 极限定义中的 "∀ε>0"；ε-δ 语言 |
| **ζ** | 黎曼 ζ 函数 | ζ(s) = Σ 1/nˢ，解析数论核心对象 |
| **η** | 效率、η-转换（λ演算） | 热效率 η = W/Q；逻辑学中的 η 规则 |
| **θ, Θ** | 角度、大 Θ 渐进记号 | 极坐标角 θ；算法复杂度 Θ(n) 表示紧确界 |
| **ι** | 很少单独使用 | 偶尔用作下标或单位向量 |
| **κ** | 曲率、条件数、热导率 | 曲线曲率 κ；矩阵条件数 cond(A) |
| **λ** | 特征值、参数、波长 | A**x** = λ**x**；泊松分布参数 λ |
| **μ** | 均值、测度、摩擦系数 | 概率分布期望 μ；勒贝格测度 μ(A) |
| **ν** | 频率、泊松比 | 物理学中 ν = f；材料力学泊松比 |
| **ξ, Ξ** | 随机变量、关联函数 | ξ 常作中间变量；Ξ 用于粒子物理或统计配分函数 |
| **π** | 圆周率（≈3.14159...） | 几何、分析、数论无处不在 |
| **ρ** | 密度、半径、相关系数 | 体密度 ρ = m/V；极坐标径向距离 |
| **σ** | 求和、标准差、曲面 | Σ 求和符号；σ 为标准差；σ-代数 |
| **τ** | 扭矩、剪切应力、时间常数 | τ = r×F；RC 电路时间常数 τ=RC |
| **φ, Φ** | 黄金比例、欧拉函数、通量 | φ = (1+√5)/2；Φ(n) 欧拉 totient 函数 |
| **χ** | 特征、卡方分布 | χ² 检验；群特征 χ(g) |
| **ψ, Ψ** | 波函数、角变量 | 量子力学 Ψ(x,t)；流函数 ψ |
| **ω, Ω** | 角频率、样本空间、欧姆 | ω = 2πf；概率论样本空间 Ω；电阻单位 Ω |

**关键记忆点**：
- **ε-δ 语言**是现代分析的基础符号体系
- **Σ（求和）与 Π（求积）** 是大写希腊字母在数学中最醒目的应用
- **Θ, O, o** 构成算法复杂度的"渐进三部曲"

## 二、物理学（Physics）

物理学中希腊字母往往携带明确的物理量纲。

| 字母 | 含义 | 公式示例 |

## 九、理工科学生的记忆策略

### 1. **按"语义家族"归类**
- **角度家族**：α, β, γ, θ, φ, ψ（几何与物理角度）
- **变化/差量家族**：δ, Δ, ε（分析、数值、误差）
- **材料/介质家族**：ε, μ, ρ, σ, τ（电磁、力学、热学性质）
- **统计/概率家族**：μ, σ, λ, π, ρ, χ（分布、相关、检验）

### 2. **注意大小写的语义分化**
- **δ**（变分/Dirac 函数） vs **Δ**（差分/判别式/拉普拉斯）
- **σ**（标准差/应力） vs **Σ**（求和/协方差矩阵）
- **ω**（角频率） vs **Ω**（欧姆/样本空间/密度参数）

### 3. **警惕"同名异义"**
同一个字母在不同领域含义可能完全不同：
- **β**：晶体管电流增益（电子）= v/c（相对论）= 回归系数（统计）
- **γ**：比热比（热力学）= 洛伦兹因子（相对论）= 欧拉常数（数学）

**阅读文献时，务必先看上下文定义，切忌望文生义。**

### 4. **书写规范**
- **ξ, ζ, ψ** 手写时容易混淆，注意 ξ 带波浪底，ζ 像带钩的 z，ψ 像三叉戟
- **ν**（nu）与 **v**（拉丁 v）在印刷体中几乎相同，手写时 ν 应带弯钩
- **ρ**（rho）与 **p**（拉丁 p）注意区分：ρ 的圈较大且偏下
- **ω**（omega）手写像"倒 U 带尾"，不要写成 w

---

**总结**：希腊字母是理工科的国际通用语汇。建议学生在学习专业课程时，主动建立"字母—领域—含义"的三维索引，遇到新符号先记录其**量纲**和**定义域**，久而久之便能形成条件反射式的符号直觉。
